# PDF_BULK_FILL

Excel-driven bulk PDF filler supporting:
- **Native PDF AcroForm Comb Fields & Checkboxes** (one letter per box, e.g., `RR-Form.pdf`)
- **Image Overlays** (e.g., employee ID card front & back)
- **Coordinate-Based Text Overlays** (backward-compatible with `TEMPLATE.xlsx` + encrypted Excel workbooks)
